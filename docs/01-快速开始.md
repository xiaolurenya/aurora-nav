# 01 · 快速开始

## 方式 A：Docker Compose（推荐，无需源码）

下载 [docker-compose.yml](../docker-compose.yml) 放到 NAS 目录，编辑环境变量改掉默认密码，然后：

    docker compose -p aurora-nav up -d

打开 http://NAS的IP:4000

- 前台：输入访问密码
- 后台：/admin 输入管理员密码
- 首次默认：前台 123456 / 后台 admin admin123，**部署后立刻改掉**

> 目录名含中文（如「导航」）必须加 -p aurora-nav，否则 Compose 报 project name must not be empty。

## 方式 B：直接 docker run

    docker pull xiaoluya/aurora-nav:latest
    docker run -d --name aurora-nav -p 4000:8787 -v ./data:/app/data \
      -e NAV_ADMIN_PASSWORD=你的管理员密码 \
      -e NAV_VIEW_PASSWORD=你的前台密码 \
      -e TZ=Asia/Shanghai \
      --restart unless-stopped xiaoluya/aurora-nav:latest

> 公开仓库不含源码，不能本地 build；镜像已发布在 Docker Hub，直接拉即可。

## 验证

    curl http://127.0.0.1:4000/api/health

返回 {"ok":true,...} 即正常。数据持久化在 ./data/data.json，升级用 docker compose -p aurora-nav pull && up -d。
