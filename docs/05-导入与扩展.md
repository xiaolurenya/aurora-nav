# 05 · 导入与浏览器扩展

## 浏览器书签（Chrome / Edge / Firefox / Safari）
书签管理器 → 导出书签 → 后台「批量导入 → 浏览器书签」上传或粘贴 → 解析预览 → 确认导入。书签文件夹名会作为强分类提示（影视/PT/工具/AI/开发/字幕/网盘…）。

## 一键获取本地浏览器历史（A 方案：扩展）

浏览器不允许网页直接读历史，提供 ZIP 和 CRX 两种安装包（后台「批量导入 → 历史记录」页可直接下载，或点 [ZIP](../aurora-nav-history-extension.zip) / [CRX](../aurora-nav-history-extension.crx)）：

1. **ZIP 方式（推荐）**：下载 ZIP 并解压成一个文件夹
2. chrome://extensions → 开「开发者模式」→ 点左上角「**加载已解压的扩展程序**」选解压后的文件夹
   > ⚠️ 不要点「打包扩展程序」（会要求私钥报错）。也可把 [CRX](../aurora-nav-history-extension.crx) 直接拖进扩展页安装；若被 Chrome 拦截，用 ZIP 方式。
3. 点工具栏 ✦ 图标，填**导航页地址**和**管理员密码**（已登录过 /admin 可留空）
4. 选天数/条数，点「一键读取并导入」

> ⚠️ 导入接口需要管理员会话，必须填管理员密码，不是前台访问密码。扩展只申请 history / storage / tabs / clipboardWrite，数据只发到你自己的导航页，无遥测。

扩展会把同一份 JSON 复制到剪贴板并打开后台，方便再逐条修改。

## B 方案：手动粘贴
从浏览器导出历史 JSON，或用任意方式生成网址列表，粘贴到后台导入框即可（见下方 C 方案）。

## C 方案：手动兜底
后台「批量导入 → 历史记录」粘贴 Chrome Takeout JSON 或每行一个网址。

## 自动获取 Logo
后台「备份与数据 → 一键获取全部网站 Logo」解析 rel=icon / apple-touch-icon / og:image，走 /api/icon 代理多源兜底并缓存，保留自定义图标与 emoji。新增/导入站点也会自动分配；全部失败显示彩色渐变首字母。
