# 04 · 后台功能

## 仪表盘
站点/分类/内外网/双栈/自动识别数、累计点击、分类分布、热门访问、快速上手。

## 网站管理
- 粘贴网址即时预览自动识别结果（分类、内外网、置信度）
- 添加/编辑/删除、批量删除与重新识别、分页筛选
- 内外网双地址、置顶、隐藏、**自定义图标（可填 URL、上传本地图片自动压缩内嵌、或直接填 emoji）**
- **双击名称或网址**可行内修改，回车保存、Esc 取消；改网址会自动重算内外网与 Logo

## 分类管理
自动创建的分类可改名/换色/换图标。**「置顶 / ↑ / ↓」或直接拖拽表格行**可调整前台显示顺序，排第一的分类会标「首页优先」，前台分区与分类胶囊按此顺序显示。删除分类时站点自动迁移到「其他收藏」。

## 识别规则
自定义「域名片段 / 关键词 → 分类」，4 个常见预设，一键重识别「其他收藏」或全部站点。

## 批量导入
- 浏览器书签 HTML / 历史记录 JSON / 文本列表
- 先预览每条的自动识别分类与内外网，可取消勾选、逐条改分类
- 每条有 ✎ 按钮可改**名称/网址**，改网址重新识别分类并更新 Logo
- 确认后自动去重入库、自动建分类

## 密码保险箱
名称/账号/密码/网址/分组/备注，显示隐藏、一键复制、搜索。前台每次点开都要输管理员密码，收起即清；可在后台设置临时解锁时长。

## 外观设置
站点信息、5 套主题（含赛博朋克）、强调色、布局、背景、圆角/列数/模糊、前台每个显示元素独立开关（含退出按钮）、自定义 CSS、搜索引擎（默认百度）、设备自适应布局开关。

## 内外网设置
自动识别开关、默认模式、内网特征串、内网探测 URL、按网络过滤、双栈站点一览。

## 安全与账号
改前台访问密码 / 管理员密码（改完全部旧会话立即失效）、会话有效期、访问密码总开关、保险箱临时解锁时长。

## 备份与数据
导出 JSON、还原、一键获取全部网站 Logo、批量重新识别、重置。
