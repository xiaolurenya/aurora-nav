# 06 · 常见问题

**Q：外网访问 NAS 服务怎么配？**
在网站管理里同时填「内网地址」和「外网地址」，前台按当前网络自动切换。

**Q：忘记管理员密码？**
删除 data/data.json（或清空 KV 的 aurora:data:v1）会用环境变量默认密码重新初始化，**但会丢失所有自定义数据**，请先导出备份。

**Q：改了前台访问密码，旧页面为什么自动退出？**
刻意设计：会话 epoch 递增，所有旧 Cookie 立即失效，刷新会跳登录页并提示「会话已失效」。

**Q：登录后报 Pbkdf2 failed？**
Cloudflare Workers 的 WebCrypto 限制 PBKDF2 迭代数 ≤ 100000，本项目已固定 100000，旧版 120000 哈希会在首次请求自动重建。见 [03-Cloudflare部署](<03-Cloudflare部署.md>)。

**Q：登录慢？**
早期版本每个请求都写 KV，已改为「仅数据变化时写入」，登录到卡片可见约 250-300 ms。

**Q：开浏览器调试模式能看到未授权数据吗？**
不能。站点/分类/保险箱全部由服务端鉴权通过后下发，前端源码不含数据；未登录页面 302、API 401。另有 CSP / X-Frame-Options / no-store / 登录限速。

**Q：保险箱能设置多久免密？**
后台「安全与账号 → 保险箱临时解锁时长（分钟）」。默认 0 = 每次点开都输管理员密码、收起即清；填 10 = 10 分钟内免密，到期自动恢复。

**Q：我已经登录了后台，为什么前台保险箱还要输密码？**
刻意设计：后台会话不等于前台保险箱授权，前台一律输管理员密码。

**Q：图标获取不到？**
图标代理有多源兜底（站点自身 → Google S2 → DuckDuckGo → icon.horse → favicon.im），全部失败会显示按域名哈希着色的彩色渐变首字母。也可填自定义图标 URL 或 emoji。

**Q：本机用 NAS IP 访问容器端口超时？**
某些 NAS 宿主网络层挂了 XDP/eBPF 程序，本机自访问自身 IP 会被拦，127.0.0.1 正常、局域网其他设备正常。与本项目无关。

**Q：CF 免费额度够吗？**
够：Workers 每天 10 万请求、KV 每天 10 万读 / 1000 写。
